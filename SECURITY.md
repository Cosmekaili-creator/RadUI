# Security policy

RadUI is pre-alpha. Run it behind HTTPS, keep it away from untrusted networks where you can, and read
`docs/SECURITY-MODEL.md` first.

## Supported versions

Only the latest commit on `main` (and the latest tagged release, once there is one) gets fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through this
repository's GitHub private vulnerability reporting ("Security" tab, "Report a vulnerability").
Include the RadUI and Radicale versions, the steps to reproduce and the impact you expect.

## What to expect

This is a small project maintained on a best-effort basis. We aim to acknowledge a report within
7 days and to tell you what we plan to do within 30 days. We ask for coordinated disclosure: please
give us a reasonable time to ship a fix before you publish details, and we will credit you in the
release notes unless you prefer not to be named.

Problems in Radicale itself should be reported to the Radicale project.
